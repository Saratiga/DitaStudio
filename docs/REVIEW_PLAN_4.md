Формат тот же, что в [REVIEW_PLAN_3.md](REVIEW_PLAN_3.md): каждый пункт — отдельный коммит с тестом, после пункта обновляются
`README.md`, `USAGE.md`, `samples/DitaStudioGuide`, `docs/TESTPLAN.md` и отметка в этом файле. Новое в этой волне: каждое
изменение внешнего вида проверяется **снимком** (окно «Автора» — через `CaptureRenderedFrame`, HTML — через Edge headless,
DOCX — через Word), а не только тестом.

Обозначения: 🟢 лёгкий (до 1 дня), 🟡 средний (1–3 дня), 🔴 сложный (от 4 дней, нужны решения);
☐ не начат, ◐ частично, ☑ готов. Номера Д1…Д14 — в порядке замечаний в файле.

## Этап 2. Баги

| № | Статус | Что | Как |
|---|---|---|---|
| Д9 🟡 | ☑ | Абзацы в ячейке — отдельными абзацами | `RealCell` (и ячейки простой таблицы `stentry`): если у ячейки есть блочные дети — собирать их через общий блочный рендер (`<p>` → абзац, `<ul>` → список, `<note>`), а не плоскими прогонами; смешанное содержимое (текст + блок) — текст первым абзацем. | Д8 🟡 | ☑ | Полоса прокрутки не прыгает при щелчке в таблице | Выяснить, кто прокручивает: `BringIntoView` у `TextArea` AvaloniaEdit, `ScrollCaretIntoView` блока (Г15) или рамка ячейки. Прокручивать только когда курсор **ушёл за границы** видимой области и только на минимально нужную величину; щелчок мышью по видимому тексту — никогда. Тест: щелчок в ячейку не меняет `Offset` |
| Д4 🟡 | ☑ | Backspace/Delete удаляют выделенный блок | Блок выделяется щелчком по рамке/метке (как таблица в Г18); Backspace и Delete удаляют его через `EditCommands`, фокус — на соседний блок; удаление, ломающее содержимое по модели (последний обязательный элемент), отказывает с пояснением в строке состояния. Отмена одной операцией. Тесты — на **все** блоки каталога: перебор по `DitaCatalog` всех элементов с блочным отображением (абзац, примечание, список и пункт, рисунок, блок кода, таблица и строка/ячейка, `fig`, `section`, `example`, `steps/step`, `dl/dlentry`, `lines`, `pre`, `p` в ячейке и т.д.) — для каждого собирается минимальный допустимый документ, блок выделяется и удаляется, проверяются: узел ушёл, документ остался допустимым по контент-модели (либо отказ с пояснением), отмена возвращает; снимок выделенного блока |
| Д13 🟡 | ☑ | Удаление одной из дублированных строк | Решение по вопросу 2: **«Удалить файл» действует только на выбранную строку**. Если на файл ссылаются другие строки карты (в этой или других картах) — удаляется только выбранная строка, файл остаётся, а в строке состояния и в вопросе сказано, сколько ссылок осталось; предложение «Удалить файл с диска» показывается, только когда выбранная строка последняя. «Убрать из карты» уже действует на одну строку — проверить тестом. Тест: две строки на один файл — удаление одной оставляет вторую и файл |
